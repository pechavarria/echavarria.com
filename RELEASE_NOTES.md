# Release notes

## v1.0 — 2026-07-26

First public release. A private family site behind an access code, hosted free
on GitHub Pages at **https://echavarria.com**.

### Hosting and DNS

- GitHub Pages serving `main` / root, HTTPS enforced (`http://` → `https://`).
- Apex `echavarria.com` is canonical; `www` CNAMEs to `pechavarria.github.io`
  and redirects to the apex.
- DNS stays at Porkbun. Nameservers were deliberately **not** moved to
  Cloudflare so the existing `fwd1`/`fwd2.porkbun.com` MX records — and the
  email forwarding that depends on them — keep working untouched.

### Pages

| Page | What it is |
|---|---|
| `index.html` | Access-code screen: crest, black ground, doodle pattern |
| `home.html` | Wordmark plus a single row of four square family buttons |
| `papati.html` `mamati.html` `sofiti.html` | Member pages for Pablo, Claudia, Sofi |
| `pablito.html` | Pablo Jr's university résumé (print/PDF ready) |

### Access gate

- Code is checked as a **SHA-256 hash**; the plaintext never appears in source.
- Unlock persists in `localStorage`. Because the stored token *is* the hash,
  changing the code invalidates every saved session automatically.
- Every gated page calls `requireAccess()`, which redirects to the login screen.
- All pages are `noindex, nofollow`.

**This is obscurity, not security.** The repo is public, so every page behind
the gate is readable directly at its URL, and a short code is trivial to guess
against a hash that ships in the open. Do not put anything private here. Real
access control needs a server — Cloudflare Access has a free tier.

### Design

- **Crest** — supplied artwork with its background removed programmatically.
  Both source files faked transparency: one had a white ground, the other a
  checkerboard painted in as opaque white and grey squares. See
  `tools/LogoAlpha2.cs`.
- **Wordmark** — inline SVG. Gold gradient lettering with a drop shadow,
  a flourish above, and hairline rules with diamond stops. Inline rather than
  `<img>` so it inherits the page font and `currentColor`.
- **Login background** — black `#08080a` with a tiling doodle pattern at 12%
  opacity: 285 icons and 340 filler marks covering the family's travels
  (Texas, Oregon, California, Colorado, France, Japan, China, Italy, Croatia,
  Spain), soccer, basketball and a lot of food. Generated by
  `tools/gen-pattern.ps1`; see that file for the packing rules.
- **Résumé** — two-column layout with a stat strip, category-coloured activity
  timeline, and print styles that produce a clean PDF.

### Tooling

Generated assets are reproducible rather than one-off blobs:

- `tools/gen-pattern.ps1` — builds `assets/pattern.svg`. Deterministic seed,
  largest-first no-overlap packing, spatial hash, seamless edge wrapping.
- `tools/icons-defs.svg` — the 60-icon library the pattern draws from.
- `tools/LogoAlpha2.cs` — strips a faked-transparency background using
  connected-component analysis.
- `tools/MakeIcon.cs` — renders the favicon PNGs and `favicon.ico`.

### Known limitations

- `assets/logo.png` is 427 KB. Gradient-rich artwork compresses poorly as PNG
  and transparency rules out JPEG. WebP would roughly halve it.
- A few pattern icons read weakly close up — the surfboard looks like a leaf,
  the nigiri like a small boat, the longhorn like a generic animal head. At 12%
  opacity they function as texture.
- Résumé content is **placeholder**, highlighted in orange on the page. Replace
  the text, drop the `ph` class, then delete the `.ph` rule from `resume.css`.
- Member pages for Pablo, Claudia and Sofi are stubs.
